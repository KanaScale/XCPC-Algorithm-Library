# 拉丁方：常用性质与结论

## 1. 定义

一个 \(n\) 阶拉丁方（Latin Square）是一个 \(n\times n\) 矩阵 \(L\)，其中元素取自

\[
\{0,1,\ldots,n-1\}
\]

并满足：

- 每一行都是 \(0,1,\ldots,n-1\) 的一个排列；
- 每一列也是 \(0,1,\ldots,n-1\) 的一个排列。

例如 \(n=4\) 时：

\[
\begin{matrix}
0&1&2&3\\
1&2&3&0\\
2&3&0&1\\
3&0&1&2
\end{matrix}
\]

就是一个 4 阶拉丁方。

---

# 2. 最基本的计数性质

## 2.1 每个符号恰好出现 \(n\) 次

任意符号 \(x\in\{0,\ldots,n-1\}\)：

- 每一行恰好出现一次；
- 一共有 \(n\) 行。

所以：

\[
\boxed{x\text{ 在整个拉丁方中恰好出现 }n\text{ 次}}
\]

整个矩阵共有：

\[
n^2
\]

个格子，也正好是：

\[
n\text{ 个符号}\times n\text{ 次出现}.
\]

---

## 2.2 每个符号的位置形成一个排列

固定某个符号 \(x\)。

设它在第 \(i\) 行出现的列为：

\[
p_x(i)
\]

由于每一行恰好出现一次 \(x\)，所以 \(p_x(i)\) 唯一。

由于每一列也恰好出现一次 \(x\)，所以：

\[
p_x(0),p_x(1),\ldots,p_x(n-1)
\]

互不相同。

因此：

\[
\boxed{p_x\text{ 是 }0,\ldots,n-1\text{ 的一个排列}}
\]

所以一个拉丁方也可以看作：

\[
\boxed{n\text{ 个排列矩阵的叠加}}
\]

---

# 3. 任意两行之间的性质

设两行分别为排列：

\[
P=(P_0,\ldots,P_{n-1}),
\qquad
Q=(Q_0,\ldots,Q_{n-1})
\]

由于每一列中元素不能重复，所以对于任意列 \(j\)：

\[
\boxed{P_j\ne Q_j}
\]

因此两个排列在任何位置都不相同。

换句话说：

\[
P^{-1}\circ Q
\]

是一个错排。

所以：

\[
\boxed{\text{任意两行逐位置比较，没有任何相同元素}}
\]

列也完全对称：

\[
\boxed{\text{任意两列逐位置比较，也没有任何相同元素}}
\]

这在“拉丁方 + 错排”类题目中很常用。

---

# 4. 行和、列和及一般函数和

因为每一行都是：

\[
0,1,\ldots,n-1
\]

的一个排列，所以每行元素和相同：

\[
\boxed{
\sum_{j=0}^{n-1}L_{i,j}
=
\frac{n(n-1)}2
}
\]

每列同理。

整个矩阵总和：

\[
\boxed{
\sum_{i,j}L_{i,j}
=
\frac{n^2(n-1)}2
}
\]

更一般地，对于任意只依赖元素本身的函数 \(f\)：

\[
\boxed{
\sum_j f(L_{i,j})
=
\sum_{x=0}^{n-1}f(x)
}
\]

对每一行都相同。

例如：

\[
\sum_j L_{i,j}^2
=
\sum_{x=0}^{n-1}x^2
\]

或者：

\[
\bigoplus_j L_{i,j}
=
0\oplus1\oplus\cdots\oplus(n-1)
\]

每一行、每一列的 XOR 也完全相同。

---

# 5. 最经典构造：循环拉丁方

定义：

\[
\boxed{
L_{i,j}=(i+j)\bmod n
}
\]

一定是 \(n\) 阶拉丁方。

固定 \(i\)，随着 \(j\) 遍历：

\[
0,\ldots,n-1
\]

有：

\[
i+j\pmod n
\]

恰好遍历所有剩余类。

固定 \(j\) 同理。

例如 \(n=5\)：

\[
\begin{matrix}
0&1&2&3&4\\
1&2&3&4&0\\
2&3&4&0&1\\
3&4&0&1&2\\
4&0&1&2&3
\end{matrix}
\]

---

# 6. 更一般的线性模构造

可以定义：

\[
\boxed{
L_{i,j}=(ai+bj+c)\bmod n
}
\]

只要：

\[
\boxed{
\gcd(a,n)=\gcd(b,n)=1
}
\]

就一定是拉丁方。

原因是固定 \(i\) 后：

\[
j\mapsto bj+\text{const}\pmod n
\]

是一个双射；

固定 \(j\) 后：

\[
i\mapsto ai+\text{const}\pmod n
\]

也是双射。

算法构造题中看到“每行每列都是排列”，可以优先尝试这种形式。

---

# 7. XOR 拉丁方

当：

\[
n=2^k
\]

时，可以定义：

\[
\boxed{
L_{i,j}=i\oplus j
}
\]

其中：

\[
0\le i,j<n.
\]

因为 \(n\) 是 2 的幂，所以：

\[
i\oplus j<n
\]

并且固定 \(i\) 时：

\[
j\mapsto i\oplus j
\]

是一个双射。

因此每行每列都是：

\[
0,\ldots,n-1
\]

的排列。

这个构造在带 XOR 条件的拉丁方题中尤其常见。

---

# 8. XOR 拉丁方的 \(2\times2\) 性质

若：

\[
L_{i,j}=p_i\oplus p_j
\]

其中 \(p\) 是 \(0,\ldots,n-1\) 的排列，则任意相邻 \(2\times2\)：

\[
\begin{matrix}
L_{i,j}&L_{i,j+1}\\
L_{i+1,j}&L_{i+1,j+1}
\end{matrix}
\]

四个元素 XOR 为：

\[
0.
\]

因为：

\[
(p_i\oplus p_j)
\oplus
(p_i\oplus p_{j+1})
\oplus
(p_{i+1}\oplus p_j)
\oplus
(p_{i+1}\oplus p_{j+1})
\]

中每个 \(p_i,p_{i+1},p_j,p_{j+1}\) 都出现两次。

所以：

\[
\boxed{\text{XOR 型拉丁方天然具有局部 }2\times2\text{ XOR}=0}
\]

这类“变量各出现两次自动抵消”的结构非常适合 XOR 构造题。

---

# 9. 行、列、符号置换保持拉丁方性质

对于任意一个拉丁方，可以进行：

- 任意行置换；
- 任意列置换；
- 对所有符号统一做一个排列映射。

得到的仍然是拉丁方。

例如对符号使用置换：

\[
\pi:\{0,\ldots,n-1\}\to\{0,\ldots,n-1\}
\]

定义：

\[
L'_{i,j}=\pi(L_{i,j})
\]

则 \(L'\) 仍然是拉丁方。

所以：

\[
\boxed{\text{行、列、符号三类对象具有高度对称性}}
\]

---

# 10. 转置仍然是拉丁方

若 \(L\) 是拉丁方，则：

\[
L^T
\]

也一定是拉丁方。

因为转置只是交换行和列。

因此：

\[
\boxed{\text{拉丁方的很多行性质都有完全对称的列版本}}
\]

---

# 11. Reduced Latin Square（约化拉丁方）

利用行、列、符号置换，可以把很多拉丁方标准化成：

\[
L_{0,j}=j
\]

并进一步令：

\[
L_{i,0}=i.
\]

即第一行和第一列都是：

\[
0,1,\ldots,n-1.
\]

这样的拉丁方称为：

\[
\boxed{\text{Reduced Latin Square}}
\]

例如：

\[
\begin{matrix}
0&1&2&3\\
1&\cdots\\
2&\cdots\\
3&\cdots
\end{matrix}
\]

这在：

- 枚举；
- 回溯；
- 搜索；
- 计数；

中非常有用，因为可以消除大量对称等价方案。

---

# 12. 任意拉丁方都可以约化

给定任意拉丁方：

1. 先通过列置换，使第一行变成：

\[
0,1,\ldots,n-1
\]

2. 再通过行置换，使第一列也变成：

\[
0,1,\ldots,n-1
\]

因此：

\[
\boxed{\text{每个拉丁方都与某个约化拉丁方等价}}
\]

这里的“等价”允许行列置换和符号重命名。

---

# 13. 与完全二分图的关系

建立完全二分图：

\[
K_{n,n}
\]

其中：

- 左侧 \(n\) 个点代表行；
- 右侧 \(n\) 个点代表列；
- 每个格子 \((i,j)\) 对应一条边。

将边 \((i,j)\) 的颜色定义为：

\[
L_{i,j}.
\]

因为每行每个符号恰好一次，所以每个左侧顶点的 \(n\) 条边颜色互不相同。

每列同理。

因此：

\[
\boxed{\text{拉丁方等价于 }K_{n,n}\text{ 的一个合法 }n\text{-边染色}}
\]

---

# 14. 每种符号形成一个完美匹配

固定符号 \(x\)。

所有：

\[
L_{i,j}=x
\]

的格子对应的边：

- 每个左侧顶点恰好连接一条；
- 每个右侧顶点恰好连接一条。

所以它们构成：

\[
\boxed{\text{一个完美匹配}}
\]

因此一个 \(n\) 阶拉丁方等价于：

\[
\boxed{K_{n,n}\text{ 的边被分解为 }n\text{ 个完美匹配}}
\]

这也是 König 线染色定理在完全二分图上的典型表现。

---

# 15. 与群运算表的关系

对于有限群 \(G\)，把：

\[
L_{a,b}=a*b
\]

定义为群运算结果。

固定 \(a\)，方程：

\[
a*x=y
\]

有唯一解：

\[
x=a^{-1}y
\]

因此每一行都是一个排列。

列同理。

所以：

\[
\boxed{\text{任意有限群的 Cayley Table 都是拉丁方}}
\]

最常见的是循环群：

\[
\mathbb Z_n
\]

它的运算表就是：

\[
L_{i,j}=i+j\pmod n.
\]

---

# 16. 但并非所有拉丁方都是群表

拉丁方对应的是比群更一般的代数结构：

\[
\boxed{\text{quasigroup（拟群）}}
\]

定义二元运算：

\[
x*y=L_{x,y}
\]

那么拉丁方条件等价于：

对于任意 \(a,b\)，方程：

\[
a*x=b
\]

有唯一解，并且：

\[
y*a=b
\]

也有唯一解。

所以：

\[
\boxed{\text{固定一个输入后，另一个输入到输出必须是双射}}
\]

---

# 17. 拉丁方的三个坐标具有对称性

每个格子可以表示为三元组：

\[
(r,c,s)
\]

表示：

\[
L_{r,c}=s.
\]

拉丁方条件等价于：

- 给定 \((r,c)\)，唯一确定 \(s\)；
- 给定 \((r,s)\)，唯一确定 \(c\)；
- 给定 \((c,s)\)，唯一确定 \(r\)。

因此：

\[
\boxed{\text{行、列、符号在组合意义上是对称的}}
\]

这也是很多拉丁方变换和同构的来源。

---

# 18. 正交拉丁方

两个同阶拉丁方 \(A,B\) 称为正交，如果所有有序对：

\[
(A_{i,j},B_{i,j})
\]

恰好把：

\[
\{0,\ldots,n-1\}^2
\]

中的 \(n^2\) 个有序对各出现一次。

即：

\[
\boxed{
(A_{i,j},B_{i,j})
\text{ 两两不同}
}
\]

这类拉丁方称为：

\[
\boxed{\text{Orthogonal Latin Squares}}
\]

---

# 19. 线性模构造正交拉丁方

若：

\[
L_a(i,j)=i+aj\pmod p
\]

其中 \(p\) 是质数，且：

\[
a\ne0
\]

那么不同的 \(a\) 可以产生两两正交的拉丁方。

更一般地，有限域 \(\mathbb F_q\) 上可构造：

\[
q-1
\]

个两两正交的 \(q\) 阶拉丁方。

所以当：

\[
n=p^k
\]

为素数幂时，存在：

\[
\boxed{n-1\text{ 个两两正交的 }n\text{ 阶拉丁方}}
\]

这是 MOLS（Mutually Orthogonal Latin Squares）的经典结论。

---

# 20. Transversal（横贯）

拉丁方中的 transversal 是选出 \(n\) 个格子，使得：

- 每行恰好选一个；
- 每列恰好选一个；
- 每个符号恰好出现一次。

也就是说同时满足：

\[
\boxed{\text{行、列、符号三者都不重复}}
\]

注意：

\[
\boxed{\text{不是每个拉丁方都一定存在 transversal}}
\]

因此不要把它当成普通拉丁方的基本性质。

---

# 21. 主对角线不一定是排列

拉丁方只要求：

- 行是排列；
- 列是排列。

并没有要求：

\[
L_{0,0},L_{1,1},\ldots,L_{n-1,n-1}
\]

互不相同。

所以：

\[
\boxed{\text{主对角线不一定是排列}}
\]

副对角线同理。

若额外要求两条主对角线都是排列，则属于更强的：

\[
\text{diagonal Latin square}
\]

条件。

---

# 22. 任意 \(2\times2\) 子矩阵没有普遍固定结构

普通拉丁方并不保证：

\[
A_{i,j},A_{i+1,j},A_{i,j+1},A_{i+1,j+1}
\]

四个元素：

- 两两不同；
- XOR 为 0；
- 和固定；
- 构成某种排列。

这些都不是一般拉丁方的必然性质。

例如：

\[
\begin{matrix}
0&1\\
1&0
\end{matrix}
\]

合法地出现重复的两个 0 和两个 1。

所以：

\[
\boxed{\text{局部 }2\times2\text{ 性质通常需要题目额外给出}}
\]

---

# 23. 循环拉丁方中的差值性质

对于：

\[
L_{i,j}=i+j\pmod n
\]

有：

\[
L_{i+1,j}-L_{i,j}\equiv1\pmod n
\]

以及：

\[
L_{i,j+1}-L_{i,j}\equiv1\pmod n
\]

所以相邻行、相邻列之间都是固定偏移。

更一般地：

\[
L_{i,j}=ai+bj+c\pmod n
\]

则：

\[
L_{i+1,j}-L_{i,j}\equiv a\pmod n
\]

\[
L_{i,j+1}-L_{i,j}\equiv b\pmod n
\]

这类线性结构在构造题中很常见。

---

# 24. XOR 型拉丁方中的差值性质

如果：

\[
L_{i,j}=p_i\oplus p_j
\]

则固定两行 \(r,s\)：

\[
L_{r,j}\oplus L_{s,j}
=
p_r\oplus p_s
\]

与 \(j\) 无关。

因此：

\[
\boxed{\text{任意两行的逐位置 XOR 为常数}}
\]

同理：

\[
\boxed{\text{任意两列的逐位置 XOR 也为常数}}
\]

这是 XOR 拉丁方非常重要的结构性质。

---

# 25. 拉丁方构造题的常见思路

遇到：

> 构造 \(n\times n\) 矩阵，每行每列都是 \(0,\ldots,n-1\) 的排列

可以优先尝试以下模板。

### 模板 1：循环平移

\[
\boxed{
A_{i,j}=i+j\pmod n
}
\]

适合普通加法、差值、循环结构。

### 模板 2：线性模构造

\[
\boxed{
A_{i,j}=ai+bj+c\pmod n
}
\]

要求：

\[
\gcd(a,n)=\gcd(b,n)=1.
\]

### 模板 3：XOR 构造

当 \(n\) 为 2 的幂：

\[
\boxed{
A_{i,j}=i\oplus j
}
\]

或：

\[
\boxed{
A_{i,j}=p_i\oplus p_j
}
\]

适合 XOR 局部条件。

### 模板 4：基础拉丁方 + 修正项

先构造：

\[
B_{i,j}
\]

保证行列排列，再定义：

\[
A_{i,j}=B_{i,j}\oplus C_{i,j}
\]

或者：

\[
A_{i,j}=B_{i,j}+C_{i,j}\pmod n
\]

让 \(C\) 负责满足额外局部条件，同时证明它不会破坏排列性。

---

# 26. 常见误区

## 误区 1：认为任意两行只是循环移位

只有循环拉丁方等特殊构造具有这个性质。

普通拉丁方的两行只是两个逐位置不同的排列，不一定互为循环移位。

---

## 误区 2：认为主对角线也是排列

不保证。

---

## 误区 3：认为任意 \(2\times2\) 四个元素都不同

不保证。

---

## 误区 4：认为所有拉丁方都来自群运算表

不成立。

群表一定是拉丁方，但拉丁方比群表更一般。

---

## 误区 5：认为任意 \(n\) 都可以用 XOR 构造

\[
A_{i,j}=i\oplus j
\]

只有在：

\[
n=2^k
\]

时才天然保证结果仍然属于：

\[
0,\ldots,n-1.
\]

---

# 27. 算法题中最值得记住的结论

\[
\boxed{\text{每个符号在全表中出现恰好 }n\text{ 次}}
\]

\[
\boxed{\text{每个符号的位置定义一个排列}}
\]

\[
\boxed{\text{任意两行逐位置没有相同值}}
\]

\[
\boxed{\text{任意两列逐位置没有相同值}}
\]

\[
\boxed{
L_{i,j}=i+j\pmod n
\text{ 是最经典构造}
}
\]

\[
\boxed{
L_{i,j}=ai+bj+c\pmod n,\ 
\gcd(a,n)=\gcd(b,n)=1
}
\]

\[
\boxed{
n=2^k
\Rightarrow
L_{i,j}=i\oplus j
\text{ 是 XOR 拉丁方}
}
\]

\[
\boxed{\text{行、列、符号都可以任意置换}}
\]

\[
\boxed{\text{每种符号对应 }K_{n,n}\text{ 中的一个完美匹配}}
\]

\[
\boxed{\text{群的 Cayley Table 一定是拉丁方}}
\]

---

# 28. 一句话总结

拉丁方的核心可以理解成：

\[
\boxed{
\text{固定任意一维后，另外一维到符号必须构成一个双射}
}
\]

因此它天然与：

- 排列；
- 完美匹配；
- 双射；
- 群运算表；
- 模运算构造；
- XOR 构造；

紧密相关。

在算法构造题里，最常用的思路通常不是直接逐格填写，而是先寻找一个形式：

\[
\boxed{A_{i,j}=f(i,j)}
\]

使得固定 \(i\) 或固定 \(j\) 时，\(f\) 都天然是一个排列映射。
