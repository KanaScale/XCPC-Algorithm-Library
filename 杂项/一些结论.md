### 一、割原理
求括号串的LPS（最长正则括号子序列）
可以枚举割点i，记：
```C++
L[i] = #'(' in s[:i]
R[i] = #')' in s[i + 1:]
```
则有：
```C++
m = min(L[i] + R[i]) 
```
背后其实能对应到一个更经典的结构：
**最大匹配 = 最小点覆盖**
也就是二分图中的 Kőnig 定理。

类似的思路在算法题里非常多，比如：
```text
最大匹配
→ 找点覆盖

最大的不相交区间
→ 找必须经过的关键点

最多能选多少对象
→ 找一种资源，每个对象至少消耗一份资源

路径/匹配/配对问题
→ 枚举 cut，看每个合法对象必须在 cut 的某一侧留下“证据”
```
所以以后看到“最大数量 / 最长子序列 / 最大匹配”这种目标，可以多问一句：
**能不能找一个 cut，使得每个答案单位都必须占用 cut 两侧某种资源之一？**
如果能，就很可能得到：
max ≤ 某个 cut 的代价
然后再尝试证明：
max = min cost(cut)
