# 后缀自动机 (SAM) 常见应用指南

后缀自动机（Suffix Automaton，简称 SAM）是一个强力且高度压缩的字符串状态机。它不仅包含了字符串所有的子串信息（通过 DAG 转移），还深刻揭示了子串之间的前缀/后缀关系（通过 Parent Tree / Suffix Link）。

由于 SAM 的每个状态节点天然代表了一个 `endpos`（或 `right`）等价类，这使得它在处理以下几类经典字符串问题时极其高效且优雅。

---

## 1. 基础子串判定与匹配

* **问题**：给定文本串 $S$ 和模式串 $P$，判断 $P$ 是否是 $S$ 的子串。
* **解法**：为文本串 $S$ 构建 SAM。然后将模式串 $P$ 从前往后在 SAM 的有向无环图（DAG）上进行状态转移。
* **判定**：如果能顺利转移完 $P$ 的所有字符，则 $P$ 是 $S$ 的子串；如果在某一步找不到对应的字符转移边，则说明 $P$ 不是 $S$ 的子串。
* **时间复杂度**：$O(|P|)$。

## 2. 本质不同的子串个数

* **问题**：求一个字符串中有多少个不重复（本质不同）的子串。
* **解法 1（利用 Parent Tree 属性）**：SAM 中每个节点 $u$ 包含的最长子串长度为 $len(u)$，最短子串长度为 $len(link(u)) + 1$。因此，节点 $u$ 包含的本质不同的子串个数恰好为 $len(u) - len(link(u))$。遍历所有节点求和即可。
* **解法 2（利用 DAG 属性）**：本质不同的子串与 SAM 从起点出发的路径一一对应。可以在 DAG 上进行拓扑排序并动态规划，计算从起点出发一共有多少条不同的路径。
* **时间复杂度**：$O(|S|)$。

## 3. 最长公共子串 (LCS)

* **问题**：给定两个字符串 $S$ 和 $T$，求它们的最长公共连续子串。
* **解法**：
    1. 为字符串 $S$ 构建 SAM。
    2. 遍历字符串 $T$ 的每个字符，在 $S$ 的 SAM 上模拟匹配，同时维护当前匹配的最大长度 $v$。
    3. 如果当前状态有目标字符的转移，则顺着转移边走，匹配长度 $v+1$。
    4. 如果没有转移，则顺着后缀链接（`link` 指针）往上跳，直到找到有目标字符转移的状态，更新当前状态和匹配长度；如果跳到了起点仍没有转移，则匹配长度归零。
    5. 匹配过程中出现过的最大 $v$ 即为答案。
* **扩展**：如果是求**多个字符串**的最长公共子串，可以构建广义 SAM（Generalized SAM），或者在一个串的 SAM 上同时运行其他所有串并维护每个节点能匹配到的最小最大长度。

## 4. 字典序第 $k$ 小的子串

* **问题**：求一个字符串所有本质不同（或位置不同）的子串中，按字典序排列的第 $k$ 小子串。
* **解法**：
    1. **预处理**：在 SAM 的 DAG 上从后往前（按拓扑序倒推）跑 DP，计算出每个状态出发能到达的路径总数（即子串总数）。如果是按“本质不同”算，每条路径权重为 1；如果是按“位置不同”算，到达节点的权重初始化为该节点的 `endpos` 集合大小。
    2. **贪心查找**：从起点开始，按字符字典序（a 到 z）尝试走转移边。如果某条转移边子树中的路径总数小于 $k$，说明第 $k$ 小子串不在这个分支，将 $k$ 减去该分支的路径数；如果大于等于 $k$，则说明第 $k$ 小子串就在该分支，顺着这条边往下走，直至找到目标。

## 5. 子串出现次数统计

* **问题**：查询某个子串 $P$ 在原串 $S$ 中出现的次数。
* **解法**：
    1. 在 SAM 的 DAG 上跑模式串 $P$，找到 $P$ 最终落入的节点 $u$（若找不到则出现次数为 0）。
    2. $P$ 的出现次数，本质上就是节点 $u$ 的 `endpos` 集合的大小。
    3. **求 endpos 集合大小**：在 Parent Tree 上按拓扑序倒推（或者对 Parent Tree 跑 DFS），每个节点的 `endpos` 大小等于其所有子节点 `endpos` 大小之和（叶子节点的初始值为 1，通常在每次 `extend` 添加新字符产生的那个状态设为 1，克隆节点设为 0）。

## 6. 最小循环移位（字典序最小的循环同构）

* **问题**：给定一个字符串 $S$，可以将它的前缀移到末尾，求所有移位中字典序最小的那个。
* **解法**：
    1. 将 $S$ 复制一份拼接在自己后面，得到 $S+S$。
    2. 对 $S+S$ 构建 SAM。
    3. 从 SAM 的起点开始，每次贪心地选择字典序最小的转移边走。
    4. 走 $|S|$ 步后得到的路径构成的字符串，就是原串的最小循环移位。

## 7. 寻找子串的所有出现位置

* **问题**：输出模式串 $P$ 在文本串 $S$ 中出现的所有起始位置。
* **解法**：
    1. 在 SAM 上转移找到 $P$ 对应的状态节点 $u$。
    2. $P$ 出现的所有结束位置，其实就是节点 $u$ 在 Parent Tree 上的子树中所有包含的实际原始结束位置。
    3. 通过遍历/DFS 节点 $u$ 在 Parent Tree 上的子树，收集所有代表前缀的节点（非克隆节点）的长度信息，即可计算出所有出现的起始/结束位置。
