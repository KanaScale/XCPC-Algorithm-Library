# Burnside 引理与 Pólya 计数整理

## 1. 这类问题在解决什么？

Burnside 引理和 Pólya 计数主要用于处理一类**带有对称等价关系的计数问题**。

典型描述：

- 一个项链可以旋转，旋转后相同视为同一种；
- 一个手链既可以旋转又可以翻转，变换后相同视为同一种；
- 正多边形顶点染色，旋转或翻转后相同视为同一种；
- 正方体各面染色，空间旋转后相同视为同一种；
- 环形排列、周期图案等需要“去掉对称重复”。

这类问题的本质是：

> 原本有很多不同的方案，但某些方案可以通过对称操作互相变换，因此应该归为同一类。

用群论语言来说：

- 所有对称操作组成一个群 \(G\)；
- 所有方案组成集合 \(X\)；
- 群 \(G\) 作用在集合 \(X\) 上；
- 互相能够通过群作用变换得到的方案属于同一个**轨道（Orbit）**。

因此：

\[
\boxed{\text{本质不同方案数}=\text{轨道数}}
\]

Burnside 引理就是用来计算轨道数的。

---

# 2. 前置概念：置换、循环与群作用

## 2.1 置换

一个对称操作本质上会把若干位置重新排列，因此可以表示成一个置换。

例如三个位置：

\[
1,2,3
\]

顺时针旋转 \(120^\circ\)：

\[
1\to2,\quad 2\to3,\quad 3\to1
\]

可以写成循环：

\[
(1\ 2\ 3)
\]

而旋转 \(240^\circ\)：

\[
1\to3,\quad 3\to2,\quad 2\to1
\]

写成：

\[
(1\ 3\ 2)
\]

虽然两个置换不同，但它们都有一个长度为 3 的循环。

---

## 2.2 循环结构

例如置换：

\[
(1\ 3\ 5)(2\ 4)
\]

表示：

- \(1,3,5\) 构成一个长度为 3 的循环；
- \(2,4\) 构成一个长度为 2 的循环。

其循环结构可以记为：

\[
a_2a_3
\]

其中 \(a_i\) 表示长度为 \(i\) 的循环的数量。

循环结构在 Burnside / Pólya 中非常重要，因为：

> 一个染色方案若在某个置换下保持不变，则同一个循环中的所有位置必须具有相同颜色。

例如：

\[
(1\ 2\ 3)
\]

作用后保持不变，则必须有：

\[
color(1)=color(2)=color(3)
\]

---

# 3. Burnside 引理

## 3.1 基本结论

设有限群 \(G\) 作用在有限集合 \(X\) 上。

对于 \(g\in G\)，定义：

\[
\operatorname{Fix}(g)=\{x\in X\mid g(x)=x\}
\]

即在操作 \(g\) 下保持不变的方案集合。

Burnside 引理：

\[
\boxed{
|X/G|
=
\frac{1}{|G|}
\sum_{g\in G}
|\operatorname{Fix}(g)|
}
\]

其中：

\[
|X/G|
\]

表示轨道数，也就是本质不同的方案数。

一句话记忆：

> **枚举所有对称操作，统计每个操作固定了多少方案，然后取平均。**

---

## 3.2 为什么要数固定点？

假设一个方案具有较强的对称性，那么它会被多个对称操作保持不变。

Burnside 的本质是：

- 对所有“方案—对称操作”的固定关系进行双重计数；
- 最终证明所有轨道平均贡献恰好为 \(|G|\)。

因此得到：

\[
\text{轨道数}
=
\frac{\text{所有操作的固定点数之和}}{\text{操作数量}}
\]

---

# 4. Burnside 中固定方案数如何计算？

这通常是做题最关键的一步。

假设：

- 有 \(n\) 个位置；
- 有 \(k\) 种颜色；
- 某个置换 \(g\) 一共有 \(c(g)\) 个循环。

因为每个循环中的位置必须同色，并且每个循环可以独立选择一种颜色，所以：

\[
\boxed{
|\operatorname{Fix}(g)|=k^{c(g)}
}
\]

因此：

\[
\boxed{
\text{答案}
=
\frac{1}{|G|}
\sum_{g\in G}
k^{c(g)}
}
\]

这是竞赛中最常见的 Burnside 公式。

---

# 5. 经典例子：长度为 \(n\) 的项链，只考虑旋转

设：

- \(n\) 个珠子排成圆环；
- 每个珠子有 \(k\) 种颜色；
- 旋转后相同视为同一种。

所有旋转共有：

\[
n
\]

种。

考虑旋转 \(r\) 个位置。

该置换的循环数为：

\[
\gcd(n,r)
\]

因为旋转以后，一个位置会不断跳：

\[
i\to i+r\to i+2r\to\cdots
\]

最终形成：

\[
\gcd(n,r)
\]

个循环。

因此该旋转下的固定染色数：

\[
k^{\gcd(n,r)}
\]

于是：

\[
\boxed{
\text{Ans}
=
\frac1n
\sum_{r=0}^{n-1}
k^{\gcd(n,r)}
}
\]

这就是最经典的 Burnside 公式之一。

---

## 5.1 按约数整理

还可以进一步按：

\[
d=\gcd(n,r)
\]

分类。

利用欧拉函数可得：

\[
\boxed{
\text{Ans}
=
\frac1n
\sum_{d\mid n}
\varphi\left(\frac nd\right)k^d
}
\]

等价地也常写成：

\[
\boxed{
\text{Ans}
=
\frac1n
\sum_{d\mid n}
\varphi(d)k^{n/d}
}
\]

两式只是换元不同。

### 经典考点

当 \(n\) 很大时，不能枚举全部 \(n\) 个旋转，但约数个数很少，因此：

> **Burnside + gcd 分类 + 欧拉函数** 是项链计数中的经典套路。

---

# 6. 手链：旋转 + 翻转

如果题目说：

> 旋转或翻转后相同都算同一种。

那么对称群不再只是旋转群 \(C_n\)，而是二面体群 \(D_n\)。

共有：

\[
2n
\]

种操作：

- \(n\) 个旋转；
- \(n\) 个翻转。

Burnside：

\[
\text{Ans}
=
\frac1{2n}
\left(
\sum_{\text{旋转}}|\operatorname{Fix}|
+
\sum_{\text{翻转}}|\operatorname{Fix}|
\right)
\]

旋转部分仍为：

\[
\sum_{r=0}^{n-1}k^{\gcd(n,r)}
\]

翻转部分需要根据 \(n\) 的奇偶分类。

---

## 6.1 \(n\) 为奇数

每条对称轴：

- 穿过 1 个顶点；
- 剩余 \(n-1\) 个顶点两两交换。

循环数：

\[
1+\frac{n-1}{2}
=
\frac{n+1}{2}
\]

因此每个翻转固定：

\[
k^{(n+1)/2}
\]

种方案。

共有 \(n\) 个翻转。

---

## 6.2 \(n\) 为偶数

翻转有两类。

### 第一类：对称轴穿过两个对顶点

有：

\[
\frac n2
\]

个这种翻转。

循环数：

\[
2+\frac{n-2}{2}
=
\frac n2+1
\]

固定方案数：

\[
k^{n/2+1}
\]

### 第二类：对称轴穿过两条对边

也有：

\[
\frac n2
\]

个。

所有位置两两交换，因此循环数：

\[
\frac n2
\]

固定方案数：

\[
k^{n/2}
\]

### 经典考点

> 翻转计数时必须根据 \(n\) 的奇偶分类。

这是 Burnside 手链题中最容易出错的地方之一。

---

# 7. Pólya 计数

## 7.1 为什么需要 Pólya？

Burnside 非常适合求：

> 一共有多少种本质不同染色？

但如果题目要求：

> 恰好使用 3 个红色、2 个蓝色、1 个绿色，有多少种本质不同方案？

仅仅计算：

\[
k^{c(g)}
\]

就丢失了“每种颜色用了多少次”的信息。

Pólya 计数就是 Burnside 的生成函数加强版。

核心思想：

> 不再只记录“有多少种固定染色”，而是用多项式记录每种颜色的使用次数。

---

# 8. 循环指标多项式

设某个置换 \(g\)：

- 长度 1 的循环有 \(c_1(g)\) 个；
- 长度 2 的循环有 \(c_2(g)\) 个；
- \(\cdots\)
- 长度 \(n\) 的循环有 \(c_n(g)\) 个。

定义群 \(G\) 的循环指标：

\[
\boxed{
Z_G(a_1,a_2,\ldots,a_n)
=
\frac1{|G|}
\sum_{g\in G}
\prod_{i=1}^n a_i^{c_i(g)}
}
\]

其中 \(a_i\) 表示长度为 \(i\) 的循环。

---

# 9. Pólya 的代换规则

假设颜色为：

\[
x_1,x_2,\ldots,x_k
\]

对于一个长度为 \(i\) 的循环：

- 如果选择颜色 \(x_1\)，这个循环有 \(i\) 个位置，因此贡献 \(x_1^i\)；
- 如果选择颜色 \(x_2\)，贡献 \(x_2^i\)；
- \(\cdots\)

所以：

\[
\boxed{
a_i
\longrightarrow
x_1^i+x_2^i+\cdots+x_k^i
}
\]

于是 Pólya 生成函数：

\[
\boxed{
P(x_1,\ldots,x_k)
=
Z_G
\left(
a_i\leftarrow
\sum_{j=1}^k x_j^i
\right)
}
\]

最终：

\[
[x_1^{m_1}x_2^{m_2}\cdots x_k^{m_k}]P
\]

就是：

> 颜色 \(x_j\) 恰好使用 \(m_j\) 次时，本质不同染色的数量。

---

# 10. 一个简单例子：3 个珠子的项链

只考虑旋转。

三个操作：

### 不旋转

置换：

\[
(1)(2)(3)
\]

循环结构：

\[
a_1^3
\]

### 旋转 \(120^\circ\)

置换：

\[
(1\ 2\ 3)
\]

循环结构：

\[
a_3
\]

### 旋转 \(240^\circ\)

置换：

\[
(1\ 3\ 2)
\]

循环结构仍然：

\[
a_3
\]

因此循环指标：

\[
\boxed{
Z_G=\frac13(a_1^3+2a_3)
}
\]

---

## 10.1 红蓝两种颜色

设颜色变量：

\[
R,B
\]

代入：

\[
a_1\to R+B
\]

\[
a_3\to R^3+B^3
\]

得到：

\[
P(R,B)
=
\frac13
\left[
(R+B)^3
+
2(R^3+B^3)
\right]
\]

展开：

\[
\boxed{
P(R,B)=R^3+R^2B+RB^2+B^3
}
\]

因此：

- 3 红：1 种；
- 2 红 1 蓝：1 种；
- 1 红 2 蓝：1 种；
- 3 蓝：1 种。

---

# 11. Burnside 与 Pólya 的关系

可以简单记为：

\[
\boxed{\text{Pólya = Burnside + 生成函数}}
\]

Burnside 中，如果一个置换有 \(c\) 个循环，\(k\) 种颜色，则固定方案数：

\[
k^c
\]

Pólya 则把每个循环的“\(k\) 种颜色选择”细分成：

\[
x_1^i+x_2^i+\cdots+x_k^i
\]

从而记录颜色使用次数。

如果把所有颜色变量都令为：

\[
x_1=x_2=\cdots=x_k=1
\]

那么：

\[
x_1^i+\cdots+x_k^i=k
\]

Pólya 就退化回 Burnside。

---

# 12. Burnside 与 Pólya 的使用区别

| 问题 | 更适合 |
|---|---|
| 求本质不同方案总数 | Burnside |
| 固定颜色数 \(k\) 的普通染色 | Burnside |
| 指定每种颜色恰好使用多少次 | Pólya |
| 统计颜色组成 | Pólya |
| 需要生成函数 | Pólya |
| 只考虑旋转/翻转去重 | 通常 Burnside |
| 带颜色数量约束的旋转/翻转去重 | Pólya |

---

# 13. 经典考法一：旋转等价的项链染色

## 题型

> 长度为 \(n\) 的环，每个位置有 \(k\) 种颜色，旋转相同视为同一种，求方案数。

### 核心

旋转 \(r\) 位：

\[
c(r)=\gcd(n,r)
\]

因此：

\[
\boxed{
\text{Ans}
=
\frac1n
\sum_{r=0}^{n-1}
k^{\gcd(n,r)}
}
\]

如果 \(n\) 较大：

\[
\boxed{
\text{Ans}
=
\frac1n
\sum_{d\mid n}
\varphi(d)k^{n/d}
}
\]

### 考察点

- Burnside；
- gcd；
- 欧拉函数；
- 约数枚举；
- 快速幂。

---

# 14. 经典考法二：手链染色

## 题型

> 长度为 \(n\) 的环，每个位置 \(k\) 种颜色，旋转和翻转相同都算一种。

### 核心

使用二面体群：

\[
|G|=2n
\]

旋转按 gcd 统计。

翻转：

- \(n\) 奇：一种类型；
- \(n\) 偶：两种类型。

### 考察点

- 对称操作分类；
- 奇偶讨论；
- 每种置换的循环数。

---

# 15. 经典考法三：恰好使用某种颜色若干次

## 题型

> \(n\) 个珠子组成项链，恰好有 \(m\) 个红珠，其余为蓝珠，旋转相同视为一种。

这类题可以直接用 Burnside，也可以从 Pólya 的角度理解。

对于某次旋转，其循环长度为：

\[
L=\frac{n}{\gcd(n,r)}
\]

每个循环必须整体染红或整体染蓝。

如果恰好需要 \(m\) 个红色位置，则必须满足：

\[
L\mid m
\]

若满足，可从：

\[
\gcd(n,r)
\]

个循环中选择：

\[
\frac mL
\]

个染红，因此固定方案数：

\[
\boxed{
\binom{\gcd(n,r)}{m/L}
}
\]

否则固定方案数为 0。

### 经典套路

> 对有“恰好用了多少颜色”的限制，先分析每个循环对数量的贡献。

这也是 Pólya 思想的具体化。

---

# 16. 经典考法四：正多边形顶点染色

## 题型

> 正 \(n\) 边形顶点染色，旋转或翻转相同视为同一种。

本质与项链 / 手链完全相同。

容易换皮为：

- 顶点放数字；
- 顶点放珠子；
- 环形座位安排；
- 环形字符串；
- 多边形顶点标记。

识别重点：

> 只要位置结构是一个圆环，并且旋转/翻转被视为相同，就应该想到循环群或二面体群。

---

# 17. 经典考法五：正方体染色

这是更典型的 Burnside 题。

例如：

> 正方体六个面用 \(k\) 种颜色染色，空间旋转后相同视为同一种。

正方体共有：

\[
24
\]

种旋转。

通常需要把旋转分类：

1. 恒等变换；
2. 绕相对面中心旋转 \(90^\circ/270^\circ\)；
3. 绕相对面中心旋转 \(180^\circ\)；
4. 绕相对顶点旋转 \(120^\circ/240^\circ\)；
5. 绕相对棱中点旋转 \(180^\circ\)。

然后分别求六个面的循环结构。

### 这类题真正考察

不是背 24 个旋转，而是：

\[
\boxed{\text{按几何性质分类等价的对称操作}}
\]

同一类别中的操作具有相同的循环结构，因此固定方案数相同。

---

# 18. 经典考法六：有限颜色数量约束

例如：

> 有红、蓝、绿三种颜色，其中红色必须恰好出现 \(a\) 次，蓝色恰好出现 \(b\) 次。

直接 Burnside 往往需要复杂分类。

Pólya 可以建立：

\[
P(R,B,G)
\]

然后求：

\[
\boxed{
[R^aB^bG^{n-a-b}]P
}
\]

这是 Pólya 最标准的用途。

---

# 19. 经典考法七：颜色带权值

例如每种颜色有权：

\[
w_1,w_2,\ldots,w_k
\]

题目要求统计总权值，或者建立关于权值的生成函数。

对于长度 \(i\) 的循环，把：

\[
a_i
\]

替换为相应的权值生成函数，例如：

\[
a_i\to
x^{iw_1}+x^{iw_2}+\cdots+x^{iw_k}
\]

然后进行 Pólya 计数。

这属于 Pólya 的生成函数应用。

---

# 20. 做题时的标准思考流程

看到“对称等价计数”时，可以按以下顺序思考。

## Step 1：确定对象集合

明确原始方案是什么。

例如：

- 染色方案；
- 排列；
- 字符串；
- 珠子颜色；
- 图案。

---

## Step 2：确定哪些变换算相同

例如：

- 只允许旋转；
- 旋转 + 翻转；
- 正方体空间旋转；
- 某些给定置换。

这些变换构成群 \(G\)。

---

## Step 3：枚举或分类群元素

重点不是一定逐个枚举，而是：

> 按循环结构分类。

同一种循环结构的操作，其固定方案数量通常相同。

---

## Step 4：计算每个操作的循环结构

例如旋转 \(r\) 位：

\[
\boxed{
\text{循环数}=\gcd(n,r)
}
\]

循环长度：

\[
\boxed{
\frac{n}{\gcd(n,r)}
}
\]

---

## Step 5：计算固定方案数

普通 \(k\) 色染色：

\[
\boxed{k^{\text{循环数}}}
\]

有颜色数量限制：

> 根据每个循环长度计算生成函数或组合数。

---

## Step 6：Burnside 取平均

\[
\boxed{
\text{Ans}
=
\frac{
\sum_g|\operatorname{Fix}(g)|
}{
|G|
}
}
\]

---

## Step 7：如果需要统计颜色组成，转 Pólya

建立循环指标：

\[
Z_G
\]

再进行：

\[
a_i\to x_1^i+\cdots+x_k^i
\]

最后取目标系数。

---

# 21. 常见易错点

## 21.1 不是除以“看起来有多少种对称”

Burnside 的分母必须是：

\[
\boxed{|G|}
\]

即实际群元素数量。

例如手链：

\[
|D_n|=2n
\]

不是 \(n\)。

---

## 21.2 不能简单用“总方案数 / 对称数”

错误思路：

\[
\frac{k^n}{n}
\]

原因是：

> 不同方案的对称性不同，轨道大小可能不同。

例如某些全同色方案旋转以后始终不变，轨道大小只有 1。

Burnside 正是为了处理这种不均匀性。

---

## 21.3 固定方案数取决于循环，不只是“不动点”

这里的：

\[
\operatorname{Fix}(g)
\]

指的是：

> 被整个置换保持不变的“方案”。

不是只数置换中有多少个位置不动。

例如：

\[
(1\ 2)(3\ 4)
\]

虽然没有单点不动，但如果：

\[
color(1)=color(2),\quad color(3)=color(4)
\]

整个染色仍然可以保持不变。

---

## 21.4 一个循环必须整体相同

这是计算固定染色数最重要的原则：

\[
\boxed{\text{同一循环中的位置必须取相同状态}}
\]

因此 \(c\) 个循环、每个循环 \(k\) 种选择：

\[
k^c
\]

---

## 21.5 翻转必须注意奇偶性

尤其在环形结构中：

- 奇数长度翻转只有一种循环结构；
- 偶数长度通常有两种。

---

## 21.6 Pólya 中循环长度必须体现在指数里

长度 \(i\) 的循环选择颜色 \(x\)，贡献：

\[
x^i
\]

而不是 \(x\)。

因此代换一定是：

\[
\boxed{
a_i\to x_1^i+x_2^i+\cdots
}
\]

---

# 22. 常用公式速查

## 22.1 Burnside

\[
\boxed{
|X/G|
=
\frac1{|G|}
\sum_{g\in G}|\operatorname{Fix}(g)|
}
\]

---

## 22.2 普通 \(k\) 色染色

若 \(g\) 有 \(c(g)\) 个循环：

\[
\boxed{
|\operatorname{Fix}(g)|
=
k^{c(g)}
}
\]

---

## 22.3 环旋转 \(r\) 位

循环数：

\[
\boxed{
\gcd(n,r)
}
\]

循环长度：

\[
\boxed{
\frac{n}{\gcd(n,r)}
}
\]

---

## 22.4 项链计数

\[
\boxed{
\frac1n
\sum_{r=0}^{n-1}
k^{\gcd(n,r)}
}
\]

或：

\[
\boxed{
\frac1n
\sum_{d\mid n}
\varphi(d)k^{n/d}
}
\]

---

## 22.5 Pólya 循环指标

\[
\boxed{
Z_G
=
\frac1{|G|}
\sum_{g\in G}
\prod_i a_i^{c_i(g)}
}
\]

---

## 22.6 Pólya 代换

\[
\boxed{
a_i
\to
x_1^i+x_2^i+\cdots+x_k^i
}
\]

---

# 23. Burnside / Pólya 的识别关键词

题目出现以下描述时应高度警觉：

- “旋转后相同视为同一种”；
- “翻转后相同视为同一种”；
- “经过置换后相同”；
- “本质不同的染色数”；
- “不同构型数”；
- “项链 / 手链”；
- “正多边形染色”；
- “正方体染色”；
- “环形排列去重”；
- “在对称意义下不同”；
- “恰好使用某种颜色若干次”。

对应思路：

```text
存在对称等价
    ↓
群作用
    ↓
轨道计数
    ↓
Burnside
    ↓
按循环结构计算固定方案数
    ↓
若还要统计颜色数量
    ↓
Pólya
```

---

# 24. 一句话总结

### Burnside

\[
\boxed{
\text{通过平均每个对称操作的固定方案数，计算本质不同的方案数。}
}
\]

### Pólya

\[
\boxed{
\text{在 Burnside 的基础上，用生成函数进一步记录每种颜色的使用数量。}
}
\]

### 算法题最重要的核心

\[
\boxed{
\text{对称操作}
\rightarrow
\text{置换循环}
\rightarrow
\text{同一循环必须同色}
\rightarrow
\text{固定方案计数}
}
\]

掌握这条链路之后，大多数 Burnside / Pólya 题目的建模方式都会比较清晰。
