### 一、关于直径
树论里一个很常用的结论：**树的所有直径都经过树的中心**
树的中心只可能有两种情况：
- 直径长度为偶数：中心是唯一一个顶点；
- 直径长度为奇数：中心是唯一一对相邻顶点，因此对应唯一一条中心边。

下面是一个找奇数直径中心边的算法：
```C++
    auto far = [&](int start){
        vi pa(n,-1),dis(n,-1);
        vi st = {start};
        dis[start] = 0;
        for(int i = 0;i < (int)st.size();i++){
            int x = st[i];
            each(y,g[x])if(y != pa[x]){
                dis[y] = dis[x] + 1;
                pa[y] = x;
                st.pb(y);
            }
        }
        int bes = start;
        fo(i,0,n)if(dis[i] > dis[bes]){
            bes = i;
        }
        return tuple{bes,dis,pa};
    };
    auto [A,dis0,pa0] = far(0);
    auto [B,disA,paA] = far(A);
    int D = disA[B];
    int R = D / 2;
    vi path;
    for(int x = B; ;x = paA[x]){
        path.pb(x);
        if(x == A) break;
    }
    reverse(all(path));
    int lef = path[R];
    int rig = path[R + 1];
```
